# 09 Prototype

Executable zero-dependency Node.js prototype.

Run:
```
cd construction-meeting-os
npm start
```
Open http://localhost:3000.

Demonstrated E2E: transcript evidence → multi-event extraction → AI Draft queue → reviewer verify → official Event. Verification API rejects missing reviewer or invalid evidence.

This is a validation prototype, not production deployment. LINE LIFF/Recall adapters remain integration work after domain/gate validation.
