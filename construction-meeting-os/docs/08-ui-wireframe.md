# 08 UI Wireframe

## Dashboard
Project selector | Meetings | Open actions | Overdue | High risks | Pending verification.

## Meeting Detail
Header/status → transcript/evidence panel → AI Draft queue → Verified Events → follow-up.

## Review Workspace
Left: timestamped transcript segment(s).
Center: AI extracted fields with confidence/needs-review.
Right: Edit / Split / Reject / Verify.
Verify button disabled when mandatory gates fail.

## Event Detail
Official record + evidence backlinks + human revision history + owner/due/status.

## Next Meeting
Auto-load open/overdue/high-risk/change items from previous verified events. User decides what is placed on agenda.
