# RC1 vendored real assets

Generated by `node scripts/vendor-rc1-assets.mjs`. Do not hand-edit binary assets.

The application remaps all core furniture/plant materials at runtime, so source glTF textures are intentionally removed where possible. This reduces payload and eliminates remote texture dependencies while preserving authored mesh geometry, hierarchy, transforms, normals and UVs. The desk lamp remains the upstream authored GLB and carries its CC-BY-4.0 attribution/license file.
